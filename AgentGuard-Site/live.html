What this checkpoint controls

Allowed
Reading a provided file or preparing a result when that action fits your task.
Paused
Any action outside the task boundary, plus every attempted external file send.
This gates actions made through AgentGuard's API workflow. It does not pause a separate chatgpt.com or claude.ai tab.

Prototype limits: the action gate is deterministic for the tools this app exposes, but it cannot guarantee detection of every off-task sentence or model behavior. No external transfer tool actually sends data; approvals are recorded as a simulation.
