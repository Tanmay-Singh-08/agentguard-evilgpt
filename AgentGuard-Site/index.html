Start here: how to use AgentGuard

Choose one path. The demo is the easiest way to see how the permission check works; the Chrome companion connects to the real ChatGPT or Claude page.

Try the demo on this page

  1. Click Load example files below. This loads safe, made-up sample documents.
  2. Click a file name to read it. Sensitive sample details are highlighted.
  3. Type what you want the AI to do in the request box.
  4. Choose a monitor scenario: safe, create an extra file, or try to send a file.
  5. Click Run task. If an alert appears, read the risk and evidence, then choose allow or stop.
  6. When it finishes, open or download the generated result from the chat preview.

Nothing leaves this demo: the assistant actions and files here are simulated in your browser.

Use it with real ChatGPT or Claude

  1. Download the Chrome companion ZIP in the Downloads section below. When it finishes, open it and choose Extract all.
  2. In Chrome, open chrome://extensions, turn on Developer mode, click Load unpacked, and select the extracted agentguard-chrome-extension folder (the folder containing manifest.json).
  3. Pin the AgentGuard shield from Chrome Extensions. If Chrome asks for site access, allow it on ChatGPT or Claude.
  4. Open ChatGPT or Claude, then refresh that tab. The AgentGuard badge should appear in the toolbar.
  5. Click the toolbar shield, pick an example, and click Insert example prompt + files.
  6. Review the prompt and attachments in the chat. Press Send yourself when ready.
  7. If the monitor spots risky text in a visible reply, it tries to pause and asks you to allow once or stop. Click the in-page AgentGuard shield to view activity.

Prototype limit: it watches visible page text. It cannot guarantee catching hidden actions or undoing something already completed.

API keys: quick visual guide

Only needed when an app calls a model API. This browser-companion preview does not need one.

OpenAI API key

1Open platform.openai.com/api-keys and sign in to the Platform.
2Choose Create new secret key and name it for your app.
3Copy it when shown and store it securely. You may not be able to view it again.

Anthropic API key for Claude

1Open console.anthropic.com/settings/keys.
2Choose Create key in the Anthropic Console.
3Copy it and keep it private. API usage may require separate billing.
Important: an API key is not your ChatGPT or Claude website password. Never paste it into a chat. This demo does not collect API keys or use real provider accounts; it uses safe sample files entirely in this browser.
